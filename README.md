# EXPAND

**The Personal Agency, Courage & Action System**

EXPAND helps people translate intentions into informed real-world action. It combines adaptive coaching with practical action partnership: diagnosing obstacles, challenging assumptions, expanding possibilities, rehearsing difficult situations and helping users choose meaningful next steps.

## Core idea

Repeated avoidance can narrow a person's lived possibilities. Considered action can reveal new paths. EXPAND helps users build the courage, audacity, skills and agency to act without confusing boldness with recklessness.

## What it does

- Diagnoses avoidance and distinguishes it from real constraints.
- Helps users challenge limiting assumptions.
- Develops courage through voluntary, graduated practice.
- Builds audacity by exploring ambitious but testable possibilities.
- Drafts messages, plans and scripts.
- Rehearses conversations, negotiations and difficult requests.
- Guides users towards concrete actions.
- Reviews outcomes and adapts future challenges.
- Uses the Expansion Radar for user-led opportunity reviews.

## Architecture

`SKILL.md` contains the core operating instructions. Detailed guidance lives in `references/`. Fictional interactions are in `examples/`. Evaluation prompts and criteria are in `evals/`.

## Installation

Install or import the `EXPAND` skill folder into an AI agent environment that supports the Agent Skills-style `SKILL.md` format. Platform-specific installation steps vary. This package does not itself install the skill into a ChatGPT account or any other platform.

## Usage examples

- "I want to ask for a raise but keep putting it off."
- "Help me approach someone senior in my industry."
- "I think I'm playing too small. Run an Expansion Radar."
- "Give me a courage challenge based on what I'm working towards."
- "Role-play a difficult conversation with my manager."
- "I didn't complete the action we agreed. Help me understand why."

## Important limitations

EXPAND is an educational and practical coaching skill, not therapy, clinical treatment or a substitute for qualified legal, medical or financial advice. It cannot independently monitor a user's life or send scheduled check-ins unless the host platform provides and authorises those capabilities. It must respect consent, safety and user autonomy.

## Validation and testing

The package includes test prompts and a scoring rubric. Mechanical checks can verify the package structure and basic metadata, but they do not establish behavioural effectiveness. Do not describe the skill as clinically validated or claim evaluation results without running the tests.
